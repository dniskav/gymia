# 0.3.5 · El asistente es la pantalla principal

Petición del usuario tras probar 0.3.4: abrir en el asistente, con botón destacado para hablar, cuadro de texto y adjuntos. La pantalla anterior debe ser la sección de Entrenamiento, con acceso a la misma conversación.

Implementación: GymRoot mantiene recepción de hojas compartidas y abre AssistantChatScreen. El botón Entrenamiento abre los controles existentes; el icono Asistente vuelve a la instancia original del chat, conservando borrador y conversación. Tus datos y ajustes de proveedor se mantienen accesibles desde el asistente. No se abre una conversación duplicada al volver desde una sesión.

## Voz y adjuntos

- Hablar con el asistente activa reconocimiento de voz del teléfono. Se pide micrófono al usarlo, no al abrir la app. El texto dictado se puede revisar antes de pulsar Enviar; no se manda automáticamente. El reconocimiento puede necesitar red y está pensado para mensajes cortos. En esta entrega usa el micrófono del teléfono, con Bluetooth desactivado explícitamente en el plugin.
- Imágenes: selector de JPG, PNG y WebP; se envían en formato multimodal apropiado para Chat Completions, Responses, Anthropic o Gemini. El modelo configurado debe admitir visión; un modelo solo de texto puede rechazar la petición. Límite 4 MB y un adjunto por mensaje.
- Archivos de audio: MP3, WAV, M4A, OGG y FLAC mediante Gemini generateContent. Para otros formatos de proveedor, se explica que se use dictado o se configure un modelo de Gemini con audio. No fingir transcripción de un archivo que no puede leer el modelo. No incluye grabación de notas de voz como archivo ni respuesta hablada del asistente.
- Los adjuntos se envían solo en la petición actual. La conversación guarda su nombre y la respuesta, pero no conserva el binario ni lo reenvía en turnos posteriores. Si hay error de API, permanece el adjunto y el borrador para reintentar.

Se distinguen errores de conexión segura, pérdida de conexión y respuestas JSON ilegibles en lugar de agruparlos bajo el mismo error genérico. No se confirma que se haya arreglado la petición fallida de 0.3.4: las capturas muestran una respuesta real de Go y un fallo posterior, pero no contienen su causa técnica.

## Verificación y pendientes

Pruebas: inicio en asistente, navegación a Entrenamiento y regreso con el mismo borrador, recuperación de conversación, serialización de imágenes para cuatro protocolos y audio para Gemini, rechazo de audio antes de enviar credenciales en proveedores no admitidos. Pruebas de integración existentes ajustadas a la nueva entrada; no se han ejecutado en dispositivo en esta entrega.

Pendiente probar micrófono, reconocimiento de voz y modelo con imágenes/audio en el teléfono del usuario. No había emulador conectado. El chat todavía no ejecuta registro de series ni escribe Sheets: esa parte del motor sigue en desarrollo. iOS tiene descripciones de permisos preparadas y continúa sin validar.

Validación local: análisis sin incidencias; suite completa de 49 pruebas y las seis pruebas de chat/pantalla pasan, incluidas dos nuevas de micrófono no disponible y tamaño de teléfono. APK release 0.3.5+8 compilada y firma verificada con el mismo certificado de las versiones anteriores. Captura de prueba a 390 × 844, sin errores de disposición.
