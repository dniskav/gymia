# 0.3.17 · Ocultar Iniciar al comunicarse con el chat

Iniciar desaparece al enfocar el campo del chat, mientras haya texto pendiente, durante la preparación/dictado por voz, con un adjunto preparado, mientras se espera la respuesta y con el teclado abierto. El botón no se puede activar mientras está oculto.

Si se cierra el teclado con el campo vacío, se sale del modo de escritura y vuelve Iniciar. Si queda un borrador, sigue oculto hasta enviarlo o vaciarlo y salir del campo. Con teclado físico se puede salir tocando fuera del campo.

Parar permanece disponible mientras haya un tramo en marcha, también al escribir o dictar. Conserva el guardado del texto pendiente al parar. El nombre de actividad, reloj, descanso y Terminar siguen disponibles.

Durante el dictado, el texto queda en modo de solo lectura y el micrófono permite terminarlo. No se deshabilita todo el campo, porque eso bloquearía también su botón de terminar dictado.

Validación: 112 tests pasan y el análisis estático no presenta incidencias. Las regresiones cubren foco, borrador sin foco, cierre del teclado, dictado y Parar con una nota pendiente; se conserva la prueba del scroll con histórico largo.

El recorrido Android pasó en el emulador de QA con almacenamiento y controles reales: escribir oculta Iniciar, quitar el foco con borrador no lo muestra, vaciar y salir permite iniciar, y Parar sigue visible al escribir durante un tramo y conserva la nota. También se verificó que el chat mantiene el final visible con teclado Android real y mensajes progresivos de un proveedor controlado.
