# 0.3.22 · Tema claro, oscuro y automático

Menú del chat → **Apariencia** permite elegir Claro, Oscuro o Automático.
El cambio se aplica al momento a las pantallas abiertas y se guarda en el móvil.
Automático sigue la luminosidad indicada por Android. Se conserva el oscuro como
valor inicial para las instalaciones que todavía no tienen una preferencia.
La elección es del dispositivo y se mantiene al cambiar de perfil.

MaterialApp usa dos temas Material 3 y un ThemeMode observable, sin recrear
bases de datos ni borrar conversaciones. La pantalla inicial también utiliza la
preferencia guardada. Citas, código, enlaces, entradas, paneles y textos
secundarios usan los colores del tema; el bloque de bienvenida mantiene su
combinación fija de verde lima y texto oscuro con contraste.

Las pruebas existentes de contraste de Markdown se ejecutan para ambos temas
(citas y código con relación mínima 4.5:1). La integración Android comprueba
cambio inmediato, recarga desde almacenamiento seguro, seguimiento del sistema,
navegación y conservación del entrenamiento local de prueba.

No añade dependencias, llamadas de red ni cambios de esquema de entrenamiento.
Las preferencias no contienen credenciales y no se incluyen en copias de datos.

Validación de entrega: 164 tests Flutter superados y análisis sin incidencias.
La comprobación visual y el recorrido Android se realizan sobre datos de prueba.

Recorrido Android superado: cambio de tema, navegación, persistencia y modo
automático comprobados sin modificar la sesión de prueba.
