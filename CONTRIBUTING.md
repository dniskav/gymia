# Contribuir a GymIA

GymIA se distribuye bajo licencia MIT. Las contribuciones se reciben mediante
issues y pull requests. Describe el problema y cómo comprobar el cambio.
Al aportar código propio, lo aportas bajo la licencia MIT del proyecto.

Consulta README.md para preparar Flutter, Android y las credenciales opcionales.
Ejecuta `flutter analyze` y `flutter test` antes de enviar cambios. Para cambios
nativos o de permisos, prueba también el recorrido afectado en un emulador
desechable. Indica qué se probó y qué queda pendiente.

Preserva los datos originales, el aislamiento por perfil y las migraciones.
No incluyas claves, tokens, archivos de firma, hojas personales, conversaciones,
copias de entrenamientos ni capturas con datos reales. Usa fixtures sintéticos.
No cambies ni elimines registros históricos para facilitar una prueba.

Las credenciales de cada colaborador y sus proyectos OAuth son propios. No se
distribuyen credenciales de producción ni acceso a cuentas del mantenedor.
